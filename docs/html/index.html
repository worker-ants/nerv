NERV — 스펙이 단일 진실이 되고, 에이전트가 조정되고, 사람이 게이트를 지키는 플랫폼

기획자·디자이너·개발자·QA가 하나의 플랫폼에서 스펙 문서와 전체 상태를 관리하고, Claude Code·Codex 에이전트가 MCP·훅·스킬로 연동되어 스펙 작성→검토→구현→테스트를 수행하며, 사람은 승인/거절/코멘트하고 누구의 어떤 세션이 무엇을 하는지 실시간으로 보는 멀티 프로젝트 × 멀티 유저(n:n) 협업 플랫폼 제안서. 4부(MVP 구체화)는 이 제안을 코드베이스·DB 스키마·API·화면·플러그인·임포터·백로그까지 "구현 착수 가능" 수준으로 구체화한다.

1. 왜 지금 필요한가 — 실측이 말하는 문제

현행 clemvion 저장소는 1인용 Claude Code 하네스(SDD+TDD 자동화)로는 업계 최고 수준의 완성도를 갖고 있다. 그러나 여러 세션·여러 사람으로 확장하는 순간, 로컬 파일과 git을 협업 데이터베이스로 쓰는 구조적 한계가 수치로 드러난다.

자기증식 루프 실측

리뷰 산출물이 코드와 같은 브랜치에 커밋되어 다음 리뷰의 diff에 이전 리뷰가 포함된다 — 한 changeset이 8라운드 리뷰를 돌았고, 마지막 라운드 리뷰 프롬프트 94파일 중 86개가 이전 리뷰 산출물이었다. 소스 diff가 컨텍스트 예산에서 밀려나는 구조적 낭비.

⚠️
조정(coordination)은 로컬의 구조적 상한에 막혔다

스펙 동시수정 자동 검출은 "병렬 작업이 다른 머신·세션이면 로컬에서 보이지 않아 신뢰할 수 없다"는 이유로 의도적으로 제거됐고(clemvion:.claude/docs/worktree-policy.md), worktree 정리 스크립트는 "살아있는 세션 앵커 레지스트리가 필요하다"고 스스로 명시한 채 타 세션을 볼 수 없다. clemvion이 로컬 한계로 포기한 기능 목록이 곧 NERV의 핵심 기능 목록이다.

업계 데이터도 같은 방향을 가리킨다. AI 도입 상위 팀에서 PR 리뷰 시간 중앙값 +441%, 무리뷰 머지 31%, 개발자당 버그 +54%(Faros AI, 22,000명 계측 — 2.2 참조). 병렬 에이전트 시대의 병목은 코드 생성이 아니라 검증과 조정이며, 이것이 NERV가 파는 가치다.

2. 무엇을 만드는가 — 3대 가치

📄 단일 진실 스펙

스펙을 DB 기반 트리 + 불변 버전 + 2축 상태(문서 승인 축 × 요구사항 구현 축)로 관리. "무엇이 구현됐고 다음이 무엇인지"를 문서가 아니라 관계 데이터가 답한다.

🤖 조정되는 에이전트

작업은 원자적 클레임+리스(lease)로 선점하고 scope 겹침을 사전 감지. 모든 세션(사용자·hostname·상태·현재 작업)이 미션 컨트롤 보드에 실시간 표시된다.

🚦 사람의 게이트

스펙 승인·변경 요청·에이전트 질문·머지가 위험도 가변 게이트로 받은 요청(Inbox)에 모인다. 지시자≠승인자, 모든 행위는 감사 로그에 (사람/AI 구분되어) 남는다.

🎯
포지셔닝 — "SDD 도구들의 Linear/GitHub"

2025년 폭발한 SDD 도구(Spec Kit 126.9k★·OpenSpec·Kiro·Tessl…)는 전부 파일 기반 1인용이며 멀티유저 요청이 공식적으로 기각된 상태다(2.1). 이 도구들이 만든 문서 어휘(requirements/design/tasks·constitution·델타) 위에 협업·상태·출처 추적 계층을 제공하는 자리가 비어 있다. NERV는 그 자리를 차지하되, git forge·Slack·기존 도구와는 연동한다(3.1 Build vs Buy).

6. 로드맵 한눈에

Phase 0 · PoC (2~3주)

MCP 최소(spec read + claim/heartbeat) + 세션 보드 + clemvion 임포트. 검증: 두 호스트·세 세션 동시 작업에서 중복 클레임 0.

Phase 1 · MVP (4~6주)

스펙 CRUD+버전+승인 · 작업 보드 · 세션 모니터 · 받은 요청 · 인앱 알림 · GitHub PR 연동 · Claude Code 플러그인 v1.

Phase 2 (4~6주)

리뷰 센터(수집·dedup·게이트 API) · Slack 알림 · Codex 지원 · CR 델타 리뷰 · 커버리지 대시보드.

Phase 3+

실시간 공동 편집(CRDT) · 임베딩 기반 중복/충돌 감지 · 분석 · SSO/감사 고도화 · SaaS화.
