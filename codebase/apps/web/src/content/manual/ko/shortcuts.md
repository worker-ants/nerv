## ⌘K — 어디로든 가기

`⌘K`(Windows·Linux 는 `Ctrl+K`)로 빠른 이동 창을 엽니다. 목록은 여러 그룹으로 나뉩니다.

| 그룹                | 들어 있는 것                                                        |
| ------------------- | ------------------------------------------------------------------- |
| **고정** · **최근** | 고정한 문서와 최근에 연 스펙·작업(입력이 비어 있을 때만)            |
| **이 프로젝트**     | 개요 · 스펙 · 작업 · 세션 · 리뷰(프로젝트 안에 있을 때)             |
| **이동**            | 홈 · 받은 요청 · 알림 · 설정의 다섯 항목 · 도움말 · 이 화면 도움말  |
| **프로젝트**        | 현재 조직의 프로젝트                                                |
| **문서**            | 입력한 검색어에 맞는 스펙·요구사항·작업(프로젝트 안에서만 찾습니다) |

검색어를 입력하면 그룹마다 이름이 맞는 항목만 남습니다. 예를 들어 "토큰" 을 입력하면 설정의 토큰 탭이, 프로젝트 이름을 입력하면 그 프로젝트가 나옵니다. 영어 단어(`inbox` · `settings` · `tokens`)로 입력해도 찾을 수 있습니다. **고정 ID를 그대로 붙여넣으면** 그 문서·요구사항·작업으로 바로 이동합니다(작업은 키로만 찾을 수 있습니다). 요구사항을 고르면 그 스펙의 요구사항 탭이 열립니다. 헤딩이 검색어와 맞는 줄을 고르면 그 절이 열립니다.

**문서 검색은 프로젝트 안에서만 됩니다.** 홈·받은 요청·알림·설정에서도 이 창으로 화면과 프로젝트에 이동할 수 있지만, 스펙·작업은 검색되지 않습니다. 입력칸의 안내 문구에도 그렇게 적혀 있습니다.

| 키              | 동작      |
| --------------- | --------- |
| `⌘K` · `Ctrl+K` | 열기·닫기 |
| `↑` · `↓`       | 결과 이동 |
| `Enter`         | 열기      |
| `Esc`           | 닫기      |

입력이 비어 있으면 **고정한 것과 최근에 연 것**이 목록 맨 위에 나옵니다. 순서는 고정한 것이 먼저입니다. **최근 목록에는 실제로 연 문서가 쌓입니다.** 트리·링크·알림으로 연 스펙과 작업도 포함됩니다. 줄마다 어느 프로젝트의 문서인지 적혀 있고, 누르면 **그 프로젝트의** 문서로 이동합니다. 다른 프로젝트나 홈에 있을 때도 마찬가지입니다. 현재 조직의 항목만 보입니다.

줄 오른쪽의 **☆** 를 누르면 그 문서가 고정되고(★), 다시 누르면 고정이 해제됩니다. 최근 목록에서는 어제 본 문서가 오늘 밀려날 수 있습니다. **매일 여는 문서 대여섯 개는 밀려나면 곤란하므로** 고정해 둘 수 있습니다. 고정은 테마·언어와 마찬가지로 **이 브라우저에** 저장됩니다.

창 안에서 `Tab` 을 누르면 포커스가 입력칸과 ☆ 버튼 사이에서만 이동하고, 창 뒤의 화면으로 나가지 않습니다. `Esc` 는 포커스가 어디에 있든 창을 닫습니다. 창을 닫으면 **열기 전에 있던 자리**로 돌아갑니다. 스크린 리더는 입력칸을 목록이 딸린 콤보 상자로 읽고, 지금 고른 줄을 선택된 항목으로 읽습니다.

## 화면을 키보드로

**`Tab` 을 처음 누르면 "본문으로 건너뛰기" 가 나타납니다.** 여기서 `Enter` 를 누르면 헤더와 사이드바를 건너뛰고 본문에서 시작합니다.

**메뉴**(왼쪽 열의 조직 · 헤더의 도움말 · 사용자)를 열면 첫 항목에 포커스가 갑니다. `Esc` 로 닫으면 메뉴를 연 버튼으로 포커스가 돌아옵니다. `Tab` 으로 메뉴 밖으로 나가면 메뉴가 자동으로 닫힙니다.

**스펙 트리는 `Tab` 순서에서 한 칸만 차지합니다.** 트리에 들어간 뒤에는 아래 키로 이동합니다. 펼침 버튼은 `Tab` 으로 선택되지 않습니다.

| 키             | 동작                                             |
| -------------- | ------------------------------------------------ |
| `↑` · `↓`      | 줄 이동                                          |
| `→`            | 접힌 가지 펼치기(펼쳐져 있으면 첫 자식으로 이동) |
| `←`            | 펼친 가지 접기(잎이면 부모로 이동)               |
| `Home` · `End` | 처음 · 끝                                        |
| `Enter`        | 그 문서 열기                                     |

**알림은 `Tab` 으로 줄을 고르고 `Enter` 로 엽니다.** 마우스로 눌렀을 때와 똑같이 읽음으로 표시하고 알림이 가리키는 곳으로 이동합니다. 줄에 포커스가 있거나 터치 화면이면 **[읽음]** 이 항상 보입니다.

## 다이얼로그와 패널

`Esc` 로 닫을 수 있는 것은 다음과 같습니다: **문서 정보** 다이얼로그([⋯ 문서 정보]), **기준선 생성** 다이얼로그, 다이어그램의 **전체 화면**, **관계 그래프**에서 고른 노드의 패널, 좁은 화면에서 띠를 눌러 연 **스펙 트리**(닫으면 띠의 버튼으로 돌아갑니다), 그리고 **한 번 더 묻는 확인 창**(`Esc` 는 취소와 같습니다). 확인 창이 떠 있는 다이얼로그에서는 `Esc` 를 눌러도 확인 창만 닫힙니다. 다이얼로그가 열려 있는 동안에는 `Tab` 을 눌러도 포커스가 다이얼로그 밖으로 나가지 않습니다. 다이얼로그를 닫으면 포커스가 **다이얼로그를 연 버튼으로** 돌아갑니다.

리뷰에서 발견을 처리할 때, 스펙을 고르는 칸에서 `↓` 를 누르면 결과 목록으로 이동합니다. `Enter` 를 누르면 첫 결과가 바로 선택됩니다.

## 받은 요청

| 키        | 동작                      |
| --------- | ------------------------- |
| `j` · `k` | 카드 사이 이동            |
| `a`       | 승인                      |
| `r`       | 거절                      |
| `c`       | 코멘트 쓰기               |
| `z`       | 보내기 전에 취소 (5초 안) |
| `x`       | 일괄 결정에 넣기·빼기     |
| `⇧X`      | 보이는 항목 모두 선택     |
| `⇧A`      | 일괄 승인                 |
| `⇧R`      | 일괄 거절                 |
| `Esc`     | 선택 해제                 |

입력창에 커서가 있을 때는 단축키가 동작하지 않습니다. 일괄 키가 **대문자**인 이유는 단건 키와 겹치지 않게 하기 위해서입니다. 한 건 처리와 스무 건 처리는 적어도 `Shift` 하나만큼은 달라야 합니다. 확인 목록이 떠 있는 동안에는 `a`·`r`·`c` 가 동작하지 않습니다.

**질문 카드에서는 `a` 와 `r` 이 동작하지 않습니다.** 질문에는 승인이나 거절 대신 답을 하므로, 답을 쓰는 `c` 만 동작합니다.

**내가 올린 결재에서는 `a` 가 동작하지 않습니다.** 자기가 올린 것을 스스로 승인하지 못하게 하는 규칙입니다. **내가 쓴 초안과 내 세션이 쓴 초안도 마찬가지입니다.** 다만 admin 이거나 멤버가 2명 미만인 프로젝트에서는 예외입니다([받은 요청](/help/inbox)).

그 밖의 경우, 결재 권한이 없는 역할로 `a` 를 누르면 조용히 무시되지 않고 **서버가 거절합니다.** **처리됨 탭의 카드에서는 버튼도 키도 동작하지 않습니다.** 이미 결정된 카드에서는 `a`·`r`·`c` 를 눌러도 아무 일도 일어나지 않습니다(누를 수 있으면 실제로 할 수 있어야 하기 때문입니다).

입력창에 커서가 있을 때는 동작하지 않습니다([작업](/help/tasks)).

## 언어

사용자 메뉴(헤더 오른쪽 이름 ▾)에서 **한국어 / English**를 고릅니다. 화면 문구와 서버가 보내는 에러 메시지가 함께 바뀝니다. **로그인·가입·초대·비밀번호 찾기 화면**에는 사용자 메뉴가 없어서 화면 아래쪽에 같은 버튼을 두었습니다. 그래서 로그인하기 전에도 언어를 바꿀 수 있습니다. 가입 확인 메일과 비밀번호 재설정 메일도 그때 고른 언어로 옵니다.

**CLI 는 언어를 따로 정합니다.** 웹과 같은 번역 문구를 쓰지만, CLI 의 언어는 웹에서 고른 값을 따르지 않습니다. 환경변수(`NERV_LANG`, 없으면 `LC_ALL`·`LANG`)로 정해집니다.

번역하지 않는 것은 세 가지입니다. **식별자**(`ready` · `approved` 같은 상태값)와 **운영자용 로그**, 그리고 **문서에 저장된 내용**입니다. 상태값이 언어마다 다르면 화면과 로그에 적힌 값이 서로 달라집니다.

## 화면 색

같은 메뉴에서 언어 바로 아래에 있는 **밝게 / 어둡게 / 시스템** 중 하나를 고릅니다. `시스템`은 직접 정하지 않겠다는 선택입니다. 이 값을 고르면 브라우저(또는 운영체제)의 설정을 따릅니다. 그래서 밤에 기기가 어두운 모드로 바뀌면 화면도 함께 어두워집니다. 밝게나 어둡게를 고르면 기기 설정보다 그 선택이 우선합니다.

**테마는 계정이 아니라 이 브라우저에 저장됩니다.** 같은 사람이라도 낮에 쓰는 노트북과 밤에 쓰는 데스크톱을 다르게 설정하기 때문입니다. 다른 기기에서는 그 기기에서 따로 고르세요.

**언어도 같은 곳에 저장됩니다.** 계정에 저장되지 않으므로, 다른 기기에서 처음 열면 브라우저 언어로 시작합니다. 그 기기에서 다시 고르면 됩니다.
