## ⌘K — 어디서든 찾기

`⌘K`(윈도·리눅스는 `Ctrl+K`)로 퀵 스위처를 엽니다. 스펙·작업·화면을 이름으로 찾습니다.

| 키              | 동작      |
| --------------- | --------- |
| `⌘K` · `Ctrl+K` | 열기·닫기 |
| `↑` · `↓`       | 결과 이동 |
| `Enter`         | 열기      |
| `Esc`           | 닫기      |

자주 가는 곳은 **핀**으로 고정하면 목록 위에 남습니다. 최근에 연 것도 함께 보여 줍니다.

## 승인함

| 키        | 동작           |
| --------- | -------------- |
| `j` · `k` | 카드 사이 이동 |
| `a`       | 승인           |
| `r`       | 거절           |
| `c`       | 코멘트 쓰기    |

입력창에 커서가 있을 때는 동작하지 않습니다.

## 언어

사용자 메뉴(헤더 오른쪽 이름 ▾)에서 **한국어 / English**를 고릅니다. 화면·에러 메시지·CLI 출력이 같은 문구 한 벌을 쓰므로, 언어를 바꾸면 세 곳이 함께 바뀝니다.

번역하지 않는 것이 셋 있습니다: **식별자**(`ready` · `approved` 같은 상태값)와 **운영자용 로그**, 그리고 **문서에 저장된 내용**입니다. 상태값이 언어마다 다르면 화면과 로그가 서로 다른 말을 하게 됩니다.

## 화면 색

밝게·어둡게는 브라우저(또는 운영체제)의 설정을 따릅니다. 앱 안에 따로 스위치를 두지 않았습니다.
