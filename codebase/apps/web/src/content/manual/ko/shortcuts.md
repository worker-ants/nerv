## ⌘K — 문서 찾기

`⌘K`(윈도·리눅스는 `Ctrl+K`)로 퀵 스위처를 엽니다. **스펙과 요구사항**을 이름으로 찾습니다 — 화면이나 설정은 찾지 못합니다.

**프로젝트 안에서만 동작합니다.** 홈·받은 요청·알림·설정처럼 주소에 프로젝트가 없는 화면에서는 창이 열려도 검색과 이동이 되지 않습니다.

| 키              | 동작      |
| --------------- | --------- |
| `⌘K` · `Ctrl+K` | 열기·닫기 |
| `↑` · `↓`       | 결과 이동 |
| `Enter`         | 열기      |
| `Esc`           | 닫기      |

입력이 비어 있으면 **고정한 것과 최근에 연 것**이 놓입니다 — 고정한 것이 위입니다.

줄 오른쪽의 **☆** 를 누르면 그 문서가 고정되고(★), 다시 누르면 풀립니다. 최근 목록은 어제 본 것이 오늘 밀려나지만 **매일 여는 대여섯은 그러면 안 되기** 때문입니다. 고정은 테마·언어와 같이 **이 브라우저에** 남습니다.

## 다이얼로그와 패널

`Esc` 로 닫는 자리가 넷 있습니다 — **새 스펙** 다이얼로그, **기준선 생성** 다이얼로그, 스펙 본문의 **링크 넣기**, 그리고 **관계 그래프**에서 고른 노드의 패널.

링크 넣기에서는 `↓` 로 결과 목록으로 내려가고 `Enter` 로 첫 결과를 바로 고릅니다.

## 받은 요청

| 키        | 동작           |
| --------- | -------------- |
| `j` · `k` | 카드 사이 이동 |
| `a`       | 승인           |
| `r`       | 거절           |
| `c`       | 코멘트 쓰기    |

입력창에 커서가 있을 때는 동작하지 않습니다.

**질문 카드에서는 `a` 와 `r` 이 듣지 않습니다.** 질문은 승인하거나 거절하는 것이 아니라 답하는 것이라서, 답을 쓰는 `c` 만 열립니다.

**내가 올린 결재에서는 `a` 가 열리지 않습니다** — 자기 요청을 자기가 승인하지 못하게 하는 규칙이고, admin 이거나 멤버가 2명 미만인 프로젝트에서는 예외입니다([받은 요청](/help/inbox)).

그 밖의 경우, 결재 권한이 없는 역할이 `a` 를 눌러도 조용히 넘어가지 않고 **서버가 거절합니다.** 처리됨 탭의 카드에서도 마찬가지입니다 — 단추는 사라지지만 키는 살아 있습니다.

## 언어

사용자 메뉴(헤더 오른쪽 이름 ▾)에서 **한국어 / English**를 고릅니다. 화면과 서버가 돌려주는 에러 메시지가 함께 바뀝니다.

**CLI 는 따로입니다.** 문구 한 벌을 같이 쓰기는 하지만, CLI 의 언어는 웹에서 고른 값이 아니라 환경변수(`NERV_LANG`, 없으면 `LC_ALL`·`LANG`)를 봅니다.

번역하지 않는 것이 셋 있습니다: **식별자**(`ready` · `approved` 같은 상태값)와 **운영자용 로그**, 그리고 **문서에 저장된 내용**입니다. 상태값이 언어마다 다르면 화면과 로그가 서로 다른 말을 하게 됩니다.

## 화면 색

같은 메뉴의 언어 바로 아래에서 **밝게 / 어둡게 / 시스템**을 고릅니다. `시스템`은 "고르지 않겠다"는 선택이라, 그동안은 브라우저(또는 운영체제)의 설정을 따라갑니다 — 기계가 밤에 어두워지면 화면도 함께 어두워집니다. 밝게나 어둡게를 고르면 그 선택이 기계 설정을 이깁니다.

**테마는 계정이 아니라 이 브라우저에 남습니다.** 같은 사람이 낮의 노트북과 밤의 데스크톱을 다르게 쓰기 때문입니다 — 다른 기계에서는 거기서 다시 고릅니다.

**언어도 같은 자리에 남습니다.** 계정을 따라다니지 않으므로, 다른 기계에서 처음 열면 브라우저 언어로 시작합니다 — 거기서 다시 고르면 됩니다.
