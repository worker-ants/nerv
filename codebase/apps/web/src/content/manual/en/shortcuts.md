## ⌘K — find anything

`⌘K` (`Ctrl+K` on Windows and Linux) opens the quick switcher. It finds specs, tasks and screens by name.

| Key             | Action               |
| --------------- | -------------------- |
| `⌘K` · `Ctrl+K` | Open / close         |
| `↑` · `↓`       | Move through results |
| `Enter`         | Open                 |
| `Esc`           | Close                |

**Pin** the places you go often and they stay at the top of the list. Recently opened items are shown too.

## Inbox

| Key       | Action             |
| --------- | ------------------ |
| `j` · `k` | Move between cards |
| `a`       | Approve            |
| `r`       | Reject             |
| `c`       | Write a comment    |

They do nothing while the cursor is in a text field.

## Language

Pick **한국어 / English** from the user menu (your name ▾ at the right of the header). Screens, error messages and CLI output all draw on one catalogue of phrases, so switching the language switches all three.

Three things are never translated: **identifiers** (status values like `ready` and `approved`), **operator logs**, and **content stored in documents**. If status values differed by language, the screen and the logs would be saying different things.

## Light and dark

Light and dark follow your browser (or operating system) setting. There is deliberately no separate switch inside the app.
