# /ko-style:check — 한국어 문체 검사

인자는 `[파일 …]`, `--staged`, `--base <ref>` 중 하나다. 인자가 없으면 스테이징한 변경을 보고, 스테이징한 것이 없으면 커밋하지 않은 변경을 본다.

## 절차

1. 검사기를 돌린다.

   ```bash
   node "${CLAUDE_PLUGIN_ROOT}/skills/ko-style/scripts/ko-lint.mjs" check $ARGUMENTS
   ```

   인자가 없으면 `--staged` 로 돌리고, 결과가 비었으면 `--base HEAD` 로 다시 돌린다(커밋하지 않은 변경).
2. 걸린 곳마다 그 문장을 앞뒤 문맥과 함께 읽는다. 인용 · 고유명사 · 예문 · 코드면 그대로 둔다.
3. 검사기가 잡지 못하는 것도 읽어서 찾는다.
   - 사물을 주어로 사람의 동작을 쓴 문장(판정이 약속한다, 로그가 알고 있다 등)
   - 영어 어순을 그대로 옮긴 문장, 한 문장에 둘 이상을 담은 문장
   - 뜻이 흐린 비유, 개발자가 실제로 쓰지 않는 번역어
4. 결과를 표로 보여 준다. 열은 `파일:행` · 지금 문장 · 고쳐 쓴 문장 · 까닭(규칙 ID)이다.
5. 사용자가 고치라고 하면 고친다. 고친 뒤 검사기를 다시 돌려 새로 걸린 것이 없는지 확인한다. 고쳐 쓴 문장이 다른 규칙에 걸리는 일이 흔하다.

## 지킬 것

- 뜻을 바꾸지 않는다. 숫자 · 경로 · 식별자 · 링크 · 코드는 그대로 둔다.
- 고쳐 쓴 문장도 같은 규칙을 지킨다. 줄표로 잇지 않고, "A가 아니라 B" 대비를 새로 만들지 않는다.
- 매뉴얼 · 화면 문구처럼 두 언어로 관리하는 글이면 다른 언어 쪽도 같은 사실을 담고 있는지 확인하라고 알린다.

Claude Code 가 아닌 도구에서는 `ko-style` 스킬 폴더의 `scripts/ko-lint.mjs` 를 쓴다.
